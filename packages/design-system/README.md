# ApexYard design system

This package contains the shared visual tokens used by the Agent SDLC, ORBIT, and AgDR sites.

The tokens mirror the ApexYard site language: Archivo display type, IBM Plex Mono interface type, a cool paper canvas, graphite text, blue links, visible rules, and an explicit light or dark theme. Site content and canonical URL configuration remain outside this package.

Import `@agent-sdlc/design-system/tokens.css` from a shared layout. Change the package version when the shared visual contract changes.
